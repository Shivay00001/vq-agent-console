VQ Agent Console

VisionQuantech · live AI-agent webhooks

Demo console. Every button below fires a live POST to your n8n instance and shows the real JSON/TwiML response. Scoring, replies, triage and plans run for real — but WhatsApp / SMS / email / call delivery needs your provider keys (Twilio, Exotel, Gmail) connected first.

How it works: form → JSON payload → POST {base}/webhook/{path} → n8n workflow → JSON response below.

Use Copy as cURL on any panel to run the same call from your terminal. Base URL is stored in this browser only.
